# PulseFit Gym

A full-stack Python website for a modern gym with class listings, trainer pages, and a contact form that stores leads in SQLite.

## Quick start

```bash
python app.py
```

Visit `http://localhost:8000`.

## Project structure

- `app.py` - HTTP server routes and SQLite persistence.
- `static/` - CSS and JavaScript assets.
- `templates/` - original Jinja templates retained for reference/design.
- `gym.db` - SQLite database (created on first run).
